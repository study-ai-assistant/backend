Квадратное уравнение

Квадратное уравнение — алгебраическое уравнение второй степени с общим видом:

a*x^2 + b*x + c = 0, a != 0,

в котором x — неизвестное, а коэффициенты a, b и c — вещественные или комплексные числа.

Выражение a*x^2 + b*x + c называется квадратным трёхчленом. Корень уравнения — это значение неизвестного x, обращающее квадратный трёхчлен в ноль, а квадратное уравнение — в верное числовое равенство. Также это значение называется корнем самого многочлена.

Элементы квадратного уравнения имеют собственные названия:
- a — первый или старший коэффициент;
- b — второй, средний коэффициент или коэффициент при x;
- c — свободный коэффициент.

Приведённым называют квадратное уравнение, в котором старший коэффициент равен единице. Такое уравнение можно получить делением исходного уравнения на a:

x^2 + p*x + q = 0,
p = b/a,
q = c/a.

Полным называют квадратное уравнение, все коэффициенты которого отличны от нуля.

Неполным называется квадратное уравнение, в котором хотя бы один из коэффициентов, кроме старшего, равен нулю.

Квадратное уравнение разрешимо в радикалах: его корни могут быть выражены через коэффициенты в общем виде.

Исторические сведения

Уже во втором тысячелетии до нашей эры вавилоняне знали, как решать квадратные уравнения. Их решение было тесно связано с практическими задачами: измерением площади земельных участков и земельными работами, связанными с военными нуждами. Развитию этих знаний способствовали математика и астрономия.

Были известны способы решения полных и неполных квадратных уравнений. Примеры в современной записи:

x^2 + x = 3/4;
x^2 - x = 14 + 1/2.

Правила решения во многом аналогичны современным, однако в вавилонских текстах не зафиксированы рассуждения, с помощью которых эти правила были получены.

Задачи, решаемые с помощью квадратных уравнений, встречаются в трактате по астрономии «Ариабхаттиам», написанном Ариабхатой в 499 году нашей эры.

Брахмагупта изложил универсальное правило решения уравнения вида:

a*x^2 + b*x = c.

При этом предполагалось, что все коэффициенты, кроме a, могут быть отрицательными. По существу сформулированное правило совпадает с современным.

Корни на множестве действительных чисел

Далее рассматриваются уравнения с действительными коэффициентами.

I. Решение через дискриминант

Дискриминантом квадратного уравнения называется величина:

D = b^2 - 4*a*c.

Если D > 0, уравнение имеет два различных действительных корня:

x1 = (-b + sqrt(D))/(2*a);
x2 = (-b - sqrt(D))/(2*a).

Если D = 0, уравнение имеет один действительный корень кратности 2, то есть два совпадающих корня:

x = -b/(2*a).

Если D < 0, действительных корней нет.

Дискриминант также связан с корнями формулой:

D = a^2*(x1 - x2)^2.

Метод решения через дискриминант универсальный, однако не единственный.

II. Уравнение с коэффициентом b = 2*k

Для уравнения:

a*x^2 + 2*k*x + c = 0,

где k = b/2, удобно вычислять четверть дискриминанта:

D/4 = k^2 - a*c.

Если k^2 - a*c > 0, корни вычисляются по формулам:

x1 = (-k + sqrt(k^2 - a*c))/a;
x2 = (-k - sqrt(k^2 - a*c))/a.

Если k^2 - a*c = 0:

x = -k/a.

Если k^2 - a*c < 0, действительных корней нет.

Для приведённого уравнения, где a = 1:

D/4 = k^2 - c;
x1 = -k + sqrt(k^2 - c);
x2 = -k - sqrt(k^2 - c).

III. Неполные квадратные уравнения

Рассматриваются три случая.

1. b = 0 и c = 0:

a*x^2 = 0;
x^2 = 0;
x = 0.

2. b = 0 и c != 0:

a*x^2 + c = 0;
a*x^2 = -c;
x^2 = -c/a.

Если -c/a > 0, есть два действительных корня с противоположными знаками:

x1 = sqrt(-c/a);
x2 = -sqrt(-c/a).

Если -c/a < 0, действительных корней нет.

3. b != 0 и c = 0:

a*x^2 + b*x = 0;
x*(a*x + b) = 0.

Следовательно:

x1 = 0;
x2 = -b/a.

IV. Частные соотношения коэффициентов

Если сумма старшего коэффициента и свободного члена равна второму коэффициенту:

a + c = b,

то корни уравнения:

x1 = -1;
x2 = -c/a.

Если сумма всех коэффициентов равна нулю:

a + b + c = 0,

то корни уравнения:

x1 = 1;
x2 = c/a.

Перед применением общих формул целесообразно проверить эти соотношения.

V. Разложение на линейные множители

Если квадратный трёхчлен удаётся представить в виде произведения:

a*x^2 + b*x + c = (k*x + m)*(l*x + n),

то уравнение равносильно условию:

(k*x + m)*(l*x + n) = 0.

Следовательно:

k*x + m = 0 или l*x + n = 0.

Корни:

x1 = -m/k;
x2 = -n/l.

Квадратный трёхчлен раскладывается на линейные множители с действительными коэффициентами, если соответствующее уравнение имеет действительные корни.

Использование формулы квадрата суммы

Если выражение имеет вид:

(a*x)^2 + 2*a*b*x + b^2,

то:

(a*x)^2 + 2*a*b*x + b^2 = (a*x + b)^2.

Уравнение:

(a*x + b)^2 = 0

имеет корень:

x = -b/a, a != 0.

Выделение полного квадрата

Для приведённого уравнения:

x^2 + p*x + q = 0

прибавляют и отнимают одно и то же число:

x^2 + p*x + (p/2)^2 - (p/2)^2 + q = 0.

После преобразования:

(x + p/2)^2 = p^2/4 - q.

Если правая часть неотрицательна, извлекают квадратный корень:

x + p/2 = ±sqrt(p^2/4 - q).

Отсюда:

x1 = -p/2 + sqrt(p^2/4 - q);
x2 = -p/2 - sqrt(p^2/4 - q).

Эту формулу также можно получить из общей формулы корней подстановкой a = 1.

VI. Теорема Виета

Прямая и обратная теоремы Виета позволяют решать некоторые приведённые квадратные уравнения устно.

Если числа x1 и x2 удовлетворяют системе:

x1 + x2 = -p;
x1*x2 = q,

то они являются корнями уравнения:

x^2 + p*x + q = 0.

Для действительных корней можно определить их знаки:

1. Если q < 0, корни имеют разные знаки. При p != 0 больший по модулю корень имеет знак, противоположный знаку p. При p = 0 корни равны по модулю и противоположны по знаку.

2. Если q > 0 и действительные корни существуют, оба корня имеют одинаковый знак, противоположный знаку p.

VII. Метод «переброски»

Метод «переброски» является модификацией теоремы Виета.

Исходное уравнение:

a*x^2 + b*x + c = 0.

Умножаем обе части на a:

(a*x)^2 + b*(a*x) + a*c = 0.

Вводим замену:

y = a*x.

Получаем приведённое уравнение:

y^2 + b*y + a*c = 0.

Решаем его относительно y, затем возвращаемся к исходной переменной:

x = y/a.
