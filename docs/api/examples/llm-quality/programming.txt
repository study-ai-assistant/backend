Python: синтаксис и примеры программ

Python — высокоуровневый язык программирования общего назначения с динамической строгой типизацией и автоматическим управлением памятью. Он ориентирован на повышение производительности разработчика, читаемости кода и его качества, а также на обеспечение переносимости программ.

Python поддерживает несколько парадигм программирования, включая процедурное, функциональное и объектно-ориентированное программирование. Поддерживается разбиение программ на модули, которые могут объединяться в пакеты.

Операторы

Условный оператор if используется для проверки условия. При наличии нескольких условий применяется необязательный блок elif, который может повторяться несколько раз. Если ни одно из условий не выполнено, выполняется необязательный блок else.

Оператор while используется для организации цикла.

Оператор for используется для перебора элементов последовательности или итератора.

Операторы try, except, else и finally используются для обработки исключений.

Оператор class определяет класс.

Оператор def определяет функцию, метод или генератор. Внутри функции return используется для возврата результата, а в генераторе yield — для выдачи очередного значения.

Оператор raise возбуждает исключение.

Оператор pass ничего не делает и используется для пустых блоков кода.

Система отступов

Одной из синтаксических особенностей Python является выделение блоков кода с помощью отступов. Поэтому в Python для обозначения границ блоков не используются операторные скобки begin/end, как в языке Паскаль, или фигурные скобки, как в Си.

Поведение и корректность программы могут зависеть от начальных пробелов в строках. Отступ определяет, какие инструкции относятся к телу функции, условного оператора или цикла.

Итераторы

В программах на Python широко используются итераторы. Цикл for может работать как с последовательностью, так и с итератором.

Большинство коллекций предоставляет итераторы. Пользователь также может определять итераторы для собственных объектов. Модуль itertools стандартной библиотеки содержит средства работы с итераторами.

Программа Hello World

Программа, выводящая приветствие, может быть записана одной строкой:

print("Hello World!")

Вычисление факториала с помощью цикла

Следующая функция вычисляет факториал числа:

def factorial(n):
    if n < 0:
        raise ArithmeticError('Факториал отрицательного числа.')
    f = 1
    for i in range(2, n + 1):
        f *= i
    return f

print(factorial(10))  # 3628800

При отрицательном аргументе функция возбуждает ArithmeticError.

Переменная f первоначально равна 1. В цикле она последовательно умножается на целые числа от 2 до n включительно. После завершения цикла функция возвращает f.

При n = 0 или n = 1 цикл не выполняется, поэтому результат равен 1.

Вычисление факториала с помощью рекурсии

Ту же задачу можно решить рекурсивно:

def factorial(n):
    if n < 0:
        raise ArithmeticError('Факториал отрицательного числа.')
    if n == 0 or n == 1:
        return 1
    else:
        return factorial(n - 1) * n

print(factorial(10))

В рекурсивной реализации при n = 0 или n = 1 функция возвращает 1. В остальных случаях она вызывает себя с аргументом n - 1 и умножает полученный результат на n.

Обе реализации при аргументе 10 возвращают 3628800.
