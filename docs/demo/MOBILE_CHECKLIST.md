# Проверка демо на телефоне

Набор готов для передачи mobile вместе с веткой feature/server-base-3.
Фактическая передача и проверка на телефоне ещё не выполнены.

1. Запустить backend по главному README и настроить адрес компьютера в приложении.
2. Вставить short-text.txt как текст, выбрать все пять режимов по очереди.
3. Загрузить short-file.txt и study-notes.pdf через существующую загрузку.
4. Загрузить long-lecture.txt или long-lecture.pdf через новый API заданий.
5. Проверить QUEUED/RUNNING, completedParts/totalParts и стадию MERGE.
6. Дождаться SUCCEEDED и показать result. Не считать HTTP 200 готовностью задания.
7. Проверить FAILED, повторную отправку и 404 после удаления/перезапуска.
8. Сохранить готовый результат в приложении до истечения серверного TTL.

Контракт: ../api/openapi.yaml. Curl-примеры: ../api/README.md.
Номер задания и содержимое учебного материала не должны попадать в публичные логи.
