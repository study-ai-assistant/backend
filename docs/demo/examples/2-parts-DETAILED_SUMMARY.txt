Последовательный сервис – компонент, который принимает фиксированное количество задач и исполняет их строго в порядке поступления.  

Время работы – суммарное время, требуемое сервису только для выполнения задач, без учёта ожидания в очереди и ограничений провайдера.  

Формула расчёта чистой (чистой) работы:  
Время работы = N × t, где N – количество задач, t – время выполнения одной задачи.

Тестирование последовательного сервиса  

1. Записывается вход – количество задач N и время одной задачи t.  
2. Проверяется полное завершение всех N задач.  
3. При любой ошибке (задержка в очереди, превышение квот) тест фиксирует явный провал; частичный успех считается ошибкой.  
4. Время ожидания в очереди и задержки из‑за квот измеряются отдельно и не включаются в расчёт чистой работы.  
5. Примеры используют синтетические данные; они не являются прогнозом реальной производительности.  

Ключевые требования тестов: фиксировать входные параметры, обеспечить завершение всех задач, обеспечить ошибку теста при любой задержке, отделять измерения чистой работы от очередей и квот.
