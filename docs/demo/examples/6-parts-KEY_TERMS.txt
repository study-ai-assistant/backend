Инвариант — условие, которое сохраняется программой до и после выполнения операции (например, уникальность идентификаторов, неотрицательное количество).

Пустая коллекция — допустимый вход, если контракт не запрещает её; считается нормальным случаем.

Ограничение входа — предельное значение размера или скорости запросов, превышение которого приводит к отказу или постановке в очередь.

Контракт (contract) — формальное описание требований к входным данным и ожидаемому результату, проверяемое перед выполнением операции и сравниваемое с наблюдаемым результатом.

Граничные значения — набор тестовых данных, включающий максимум допустимого, значение на единицу меньше и значение на единицу больше, используемый для проверки поведения системы на границе диапазона.

Линейный поиск — алгоритм последовательного сравнения элементов с образцом; в худшем случае требует n сравнений для n элементов.

Бинарный поиск — алгоритм деления отсортированного диапазона пополам; корректен только при предварительно отсортированных данных.

Сложность O(n) — асимптотическая оценка количества операций линейного поиска в худшем случае.

Рост затрат — увеличение объёма ресурсов (время, память) при росте размера входных данных, измеряется эмпирически.

Ограничение запросов — максимальное количество запросов, которое сервер может обработать за фиксированный период; превышение требует отказа или постановки в очередь.

Очередь заданий — структура, сохраняющая задания в порядке поступления и обслуживаемая последовательно одним исполнителем.

Идентификатор задания — уникальный токен, выдаваемый клиенту для последующего запроса статуса выполнения.

Состояния задания — набор возможных статусов (в очереди, выполняется, готово, ошибка), каждый из которых имеет своё значение для клиента.

Временное хранение — механизм сохранения данных на ограниченный срок с последующим автоматическим удалением (при перезапуске процесс очищает память, требуя повторной отправки данных).

Код отказа — стандартизированный ответ сервера, одинаковый при повторных превышениях лимита, позволяющий клиенту понять причину отказа.

Освобождение ресурсов — процесс очистки памяти и других ресурсов после завершения работы функции.

Квота — ограничение на количество запросов или объём данных, которое может быть использовано за определённый промежуток времени.

Наблюдаемый результат — фактический ответ сервера, полученный после выполнения запроса, используемый для валидации соответствия контракту.

HTTP‑метод GET — запрос, предназначенный только для чтения состояния ресурса без его изменения.

HTTP‑метод POST — запрос, создающий новый ресурс или инициирующий действие на сервере.

Код 202 — ответ сервера, означающий, что задание принято, но результат ещё не готов; клиент должен опрашивать указанный в заголовке Location адрес.

Условие проверки — требуемое действие, выполняемое до начала работы, чтобы убедиться, что система готова к обработке (например, проверка лимита или наличия необходимых данных).

Успешный исход — ответ сервера, подтверждающий выполнение конкретного запроса и наличие итогового результата.

Отказ — сообщение об ошибке, указывающее причину невозможности выполнить запрос (например, превышение лимита или ошибка внешнего сервиса).

Повторная попытка — ситуация, когда клиент получает отказ и должен отправить запрос заново, предоставив сведения о предыдущем запросе (идентификатор, параметры, статус).

Лимит — предельно допустимое количество запросов или ресурсов (например, 50 запросов в минуту), превышение которого приводит к одинаковому коду отказа.

Согласованные поля — данные, которые одновременно читающие клиенты должны видеть одинаковыми (например, число завершённых частей, не превышающее общее число частей).

Перезапуск — процесс повторного запуска процесса, после которого очищается временно хранимая память и может потребоваться повторная отправка данных клиентом.

Пиковая память — максимальный объём оперативной памяти, использованный во время выполнения запроса.

Число вызовов — количество обращений к функции/методу за один тестовый запуск.

Длительность — время, затраченное на обработку запроса от начала до завершения.

Таймаут — максимальное время выполнения операции, после которого процесс принудительно завершается.

Секретный ключ — конфиденциальный параметр, хранящийся только на сервере и не передающийся в клиентское приложение, репозитории или логи.

Лимит количества заданий — ограничение на число одновременно обрабатываемых запросов, превышение которого приводит к отказу или постановке в очередь.

Число завершённых частей — количество частей задачи, успешно обработанных к текущему моменту.

Общее число частей — суммарное количество частей, запланированных для выполнения задачи.

Успешное задание — запрос, получивший итоговый результат без ошибок выполнения.

Успешный ответ сервера — подтверждение выполнения конкретного запроса, не гарантирующее отсутствие ошибок в других документах.

Содержательная проверка — сопоставление полученных определений и вычислений с исходным материалом для выявления ограничений и их воспроизведения.
