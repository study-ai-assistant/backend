# Первоначальная калибровка

В этом прогоне максимум completion составлял 800 для части и 1600 для объединения.
Пять режимов двухчастного текста завершились успешно. Третья часть следующего
материала получила finish_reason=length; задание остановлено с безопасной ошибкой.
В measurements.json поле benchmark-4-parts.txt соответствует нынешнему
long-lecture.txt: это те же четыре раздела. Файл переименован при подготовке
окончательного набора, чтобы не хранить два одинаковых входа.

Токены неудачного ответа не были переданы в метаданные первым вариантом клиента,
поэтому сумма успешных частей не является полным расходом попытки.
В итоговом клиенте usage обрезанного ответа учитывается, если провайдер его сообщил.
Эти файлы сохранены как доказательство найденного ограничения, не как лучшие
ответы для показа. Итоговые примеры находятся в ../../examples.
