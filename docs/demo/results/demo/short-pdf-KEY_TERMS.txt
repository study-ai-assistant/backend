Алгоритм — конечная последовательность понятных исполнителю шагов для решения задачи

Линейный поиск — алгоритм, просматривающий элементы массива последовательно; работает в неотсортированном массиве и в худшем случае проверяет все n элементов

Бинарный поиск — алгоритм, требующий отсортированного массива; после каждого сравнения отбрасывает половину оставшегося диапазона, число шагов растёт пропорционально log n

Модульный тест — проверка небольшой части программы изолировано от внешних систем

Заглушка — заменяющая зависимость предсказуемым поведением объект, например возвращающий заранее заданный ответ вместо реального вызова

Интеграционный тест — проверка совместной работы нескольких компонентов системы

HTTP‑тест — отправка настоящего HTTP‑запроса локальному серверу с проверкой кода ответа, заголовков и тела

Положительный сценарий — тест, демонстрирующий корректную работу системы при правильных данных

Отрицательный сценарий — тест, проверяющий правильную обработку ошибки при неверных данных

Воспроизводимость тестов — требование, чтобы запуск тестов не зависел от доступности внешних API или секретных ключей

Синтетические данные — искусственно созданные данные, используемые для тестирования и демонстрации проекта
