Алгоритм – конечная последовательность понятных исполнителю шагов, обеспечивающих решение задачи. Один и тот же результат может быть получен разными алгоритмами; различаются время выполнения и расход памяти.

Линейный поиск
- Принцип: последовательный просмотр элементов массива.
- Применимость: работает в неотсортированном массиве.
- Сложность в худшем случае: проверка всех n элементов → O(n).
- Преимущество: простота реализации, отсутствие требований к упорядочиванию данных.

Бинарный поиск
- Требование: массив должен быть отсортирован.
- Принцип: после каждого сравнения отбрасывается половина оставшегося диапазона.
- Сложность: число шагов растёт пропорционально log₂ n → O(log n).
- Требует предварительной сортировки (если массив не отсортирован, её стоимость учитывается отдельно).

Выбор алгоритма
- Перед применением необходимо проверить условия применимости (наличие сортировки, размер данных и т.п.), а не только асимптотическую скорость.
- Для небольших массивов линейный поиск может быть предпочтительнее, несмотря на более высокую асимптотическую оценку, из‑за меньших накладных расходов и простоты.
