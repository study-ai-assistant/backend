Алгоритм — конечная последовательность понятных исполнителю шагов для решения задачи  

Линейный поиск — алгоритм, просматривающий элементы массива последовательно; работает в неотсортированном массиве и в худшем случае проверяет все n элементов  

Бинарный поиск — алгоритм, требующий отсортированного массива; после каждого сравнения отбрасывает половину оставшегося диапазона, число шагов растёт пропорционально логарифму n  

Условие применимости — требования, которым должен удовлетворять алгоритм (например, наличие сортировки массива), проверяемые перед выбором алгоритма  

Асимптотическая оценка — характеристика роста времени или расхода памяти алгоритма при увеличении размера входных данных, например O(n) для линейного поиска и O(log n) для бинарного поиска  

Худший случай — ситуация, при которой алгоритм выполняет максимальное число шагов (для линейного поиска — проверка всех n элементов)  

Отсортированный массив — массив, элементы которого упорядочены, обязательное требование для применения бинарного поиска.
