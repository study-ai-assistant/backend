Модульный тест — проверка небольшой части программы отдельно от внешних систем.  

Заглушка — заменяющая зависимость имитация с предсказуемым поведением, например, возврат заранее заданного ответа вместо вызова реальной модели.  

Интеграционный тест — проверка совместной работы нескольких компонентов программы.  

HTTP‑тест — отправка настоящего HTTP‑запроса к локальному серверу с последующей проверкой кода ответа, заголовков и тела.  

Положительный сценарий — тест, показывающий, что корректный запрос работает как ожидается.  

Отрицательный сценарий — тест, проверяющий, что при неверных данных возвращается понятная ошибка.  

Воспроизводимые тесты — тесты, результаты которых не зависят от доступности внешних API или секретных ключей; их запуск всегда даёт одинаковый результат.  

curl — утилита командной строки для отправки HTTP‑запросов, используемая для проверки работы API в дополнение к автоматическим тестам.
