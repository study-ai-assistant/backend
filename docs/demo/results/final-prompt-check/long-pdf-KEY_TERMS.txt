Инвариант — условие, сохраняемое программой до и после операции.

Граница изменения данных — момент проверки инварианта; при его нарушении операция завершается ошибкой без изменения состояния.

Пустая коллекция — допустимый вход, если контракт явно не запрещает её.

Ограничение входа — предел размера или частоты запросов, при превышении которого сервер сообщает отказ или ставит запрос в очередь.

Контракт (Contract) — формальное описание требований к входным данным и ожидаемому результату функции, используемое для сравнения с наблюдаемым результатом.

Граничные значения — набор тестовых входов, включающий допустимый максимум, значение на единицу меньше и значение на единицу больше, проверяющих поведение системы на границах.

Линейный поиск — последовательное сравнение каждого элемента с образцом; в худшем случае требует n сравнений для n элементов.

Бинарный поиск — поиск в отсортированном массиве с делением диапазона пополам; требует предварительной сортировки.

Асимптотический анализ — оценка роста затрат при увеличении объёма входных данных без указания точного времени выполнения.

Ограничение — максимальное количество запросов, которое сервер может обработать за единицу времени; превышение приводит к отказу или постановке в очередь.

Очередь — структура, в которой задания хранятся в порядке поступления и обрабатываются последовательно исполнителем.

Исполнитель — процесс или поток, берущий следующее задание из очереди только после завершения текущего.

Статус задания — информация, предоставляемая клиенту о текущем состоянии задания (в очереди, выполняется, готово, ошибка).

Прогресс — показатель количества завершённых частей задания, а не оценка оставшегося времени.

Временное хранение — хранение данных с указанием срока удаления; после перезапуска память очищается, требуя повторной отправки клиентом.

Освобождение ресурсов — процесс удаления всех временных данных после завершения задания, чтобы они не занимали память.

Квота — ограничение количества одновременно обрабатываемых частей; ожидание квоты учитывается отдельно от чистого времени обработки.

Лимит — предельное количество запросов или ресурсов; превышение должно возвращать одинаковый код ошибки при повторе.

Повторный POST — повторный запрос создания задания, который может привести к созданию второго задания, если не гарантирована идемпотентность.

Код 202 — ответ сервера, указывающий, что задание принято, но результат ещё не готов; клиент должен опрашивать адрес из заголовка Location.

Ограниченная очередь — механизм, в который помещаются запросы, превысившие лимит, вместо их тихой потери.

Условие — проверка, которую необходимо выполнить до начала работы, чтобы гарантировать корректность дальнейшего выполнения.

Успешный исход — результат, при котором сервер подтверждает выполнение конкретного запроса и возвращает ожидаемый ответ без ошибок.

Отказ — ответ сервера, указывающий на невозможность выполнения запроса (например, превышение лимита или ошибка внешнего сервиса).

Повторная попытка — ситуация, когда клиент после отказа должен отправить запрос заново, предоставив необходимые сведения (например, идентификатор задачи и текущий статус).

Согласованные поля — набор полей, в котором число завершённых частей не превышает общее число частей и которые должны быть одинаковыми у разных клиентов, читающих одно состояние.

Перезапуск — процесс, при котором память очищается, требующий от клиента повторной отправки данных для продолжения работы.

Тест — проверка с известными входными данными и ожидаемым результатом, позволяющая подтвердить корректность поведения системы.

Пиковая память — объём памяти, достигаемый процессом при выполнении запроса; измеряется отдельно и не заменяет оценку качества ответа.

Число вызовов — количество обращений к функции или сервису в ходе обработки; фиксируется независимо от других метрик.

Длительность — время выполнения операции от начала до завершения; учитывается отдельно от памяти и числа вызовов.

Лимит количества заданий — ограничение на количество одновременно обрабатываемых запросов, предотвращающее накопление данных в памяти.

Таймаут — предельное время, отведённое на разбор или выполнение операции; при превышении вызывается отказ.

Секретный ключ — конфиденциальный параметр, хранящийся только на сервере и не попадающий в клиентские приложения, репозитории или журналы.

Число завершённых частей — количество частей задачи, отмеченных как завершённые.

Общее число частей — суммарное количество всех частей задачи.

Успешное задание — задание, содержащее итоговый результат и считающееся выполненным.

Ответ сервера — сообщение, подтверждающее выполнение конкретного запроса, но не исключающее ошибок в других документах.

Содержательная проверка — проверка, при которой сравниваются определения и вычисления с исходным материалом, фиксируются ограничения и способ их воспроизведения.
