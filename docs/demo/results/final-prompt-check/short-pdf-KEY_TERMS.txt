Алгоритм — конечная последовательность понятных исполнителю шагов для решения задачи.

Линейный поиск — алгоритм, который просматривает элементы массива последовательно и может работать в неотсортированном массиве; в худшем случае проверяет все n элементов.

Бинарный поиск — алгоритм, требующий отсортированного массива; после каждого сравнения отбрасывает половину оставшегося диапазона, число шагов растёт пропорционально логарифму n.

Модульный тест — проверка небольшой части программы отдельно от внешних систем.

Заглушка — заменяет зависимость предсказуемым поведением, например, вместо вызова внешней модели возвращает заранее заданный ответ.

Интеграционный тест — проверка совместной работы нескольких компонентов системы.

HTTP‑тест — отправка настоящего HTTP‑запроса локальному серверу с проверкой кода ответа, заголовков и тела.

Положительный сценарий — проверка того, что корректный запрос работает как ожидается.

Отрицательный сценарий — проверка понятной ошибки при неверных данных.

Воспроизводимость тестов — требование, чтобы обычный запуск тестов не зависел от доступности внешних API или секретных ключей.

Синтетические данные — искусственно сгенерированные данные, используемые в примерах проекта.
