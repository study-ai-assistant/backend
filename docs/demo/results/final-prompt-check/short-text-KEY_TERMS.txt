Алгоритм — конечная последовательность понятных исполнителю шагов для решения задачи

Линейный поиск — метод последовательного просмотра элементов массива, работающий в неотсортированном массиве; в худшем случае проверяет все n элементов

Бинарный поиск — метод поиска в отсортированном массиве, при каждом сравнении отбрасывающий половину оставшегося диапазона; число шагов растёт пропорционально логарифму n

Асимптотическая оценка — характеристика роста количества шагов алгоритма в зависимости от размера входных данных, используемая для сравнения эффективности алгоритмов

Условия применимости — требования к входным данным (например, сортировка массива), которые необходимо проверить перед выбором алгоритма.
