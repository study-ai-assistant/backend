Что такое алгоритм
Алгоритм — это конечный набор чётких инструкций, которые человек или программа могут выполнить, чтобы решить задачу. Последовательность шагов фиксирована и завершается после выполнения последнего шага.

Разные алгоритмы, один результат
Для одной и той же задачи может существовать несколько алгоритмов. Они дают одинаковый итог, но могут различаться по времени выполнения и потреблению памяти.

Линейный поиск
- Просматривает элементы массива один за другим, начиная с первого.
- Работает независимо от того, отсортирован массив или нет.
- В худшем случае (когда нужный элемент находится в конце или его нет) проверяется каждый из n элементов, т.е. O(n) шагов.

Бинарный поиск
- Требует, чтобы массив был отсортирован.
- На каждом шаге сравнивает искомый элемент с серединой текущего диапазона и отбрасывает половину диапазона.
- Число шагов растёт как логарифм от размера массива, то есть O(log n).

Как выбирать алгоритм
Перед тем как решить, какой алгоритм использовать, необходимо проверить, удовлетворяют ли данные условиям его применимости (например, наличие сортировки для бинарного поиска). Скорость — это лишь один из факторов.

Практический совет
Если массив маленький, простой линейный поиск может оказаться удобнее, даже если его асимптотическая оценка хуже, потому что его реализация проще и накладные расходы минимальны.
