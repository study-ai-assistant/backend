Последовательная обработка — выполнение задач сервисом строго в порядке их поступления, без параллельного запуска.

Поступление в порядке очереди (Arrival order) — правило, при котором задачи обрабатываются согласно их позиции в очереди, первая пришла‑первая обслужена.

Время чистой работы — суммарное время, требуемое только для выполнения задач без учёта ожидания в очереди и ограничений провайдера.

Задержка в очереди (Queue waiting) — дополнительное время, которое задача проводит в ожидании начала обработки.

Ограничения квоты провайдера (Provider quota delays) — ограничения внешнего сервиса (например, ограничение количества запросов), влияющие на общую продолжительность выполнения и вызывающие дополнительное время ожидания.

Синтетические данные (Synthetic data) — искусственно сгенерированный набор входных значений, используемый в тестах и не отражающий реальную производительность.

Чёткая неудача (Clear failure) — результат теста, при котором проверка явно фиксирует полное несоответствие, а не частичный или условный успех.

Запись входных данных тестом — процесс фиксации переданных в сервис параметров для последующего сравнения с ожидаемыми результатами.

HTTP‑контракт — соглашение о том, какие запросы и ответы допускает сервис.

Resource limits (ограничения ресурсов) — максимальное количество одновременно обрабатываемых задач, определяемое провайдером.

Task (задача) — единица работы, которую сервис принимает и обрабатывает последовательно.
