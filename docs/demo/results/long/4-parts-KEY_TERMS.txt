Инвариант — условие, сохраняемое программой до и после выполнения операции.  

Пустая коллекция — допустимый входной набор, если контракт не запрещает его использование.  

Ограничение входа — предел размера или частоты входных запросов, при превышении которого сервер отказывает или ставит запрос в очередь.  

Контракт — формальное описание требований к входным параметрам функции и ожидаемого результата, проверяемое при ревью.  

Граничные значения (boundary values) — набор тестовых параметров, включающий максимальное допустимое значение, значение на единицу меньше и значение на единицу больше ограничения.  

Согласованные поля — данные, которые несколько клиентов видят одинаковыми (например, число завершённых частей не превышает общее число частей).  

Временное хранение — состояние или данные, сохраняемые лишь до перезапуска процесса; после перезапуска требуется их повторная отправка, либо они удаляются.  

Код отказа — идентификатор ошибки, одинаковый для всех повторных превышений лимита.  

Линейный поиск — последовательное сравнение элементов с образцом, в худшем случае требующее n сравнений.  

Бинарный поиск — поиск в отсортированном диапазоне, делящий его пополам; требует предварительной сортировки.  

Оценка O(n) — асимптотическое описание роста затрат при увеличении объёма входных данных, не привязанное к конкретному времени выполнения.  

Ограничение запросов — максимальное число запросов, которое сервер может обработать за единицу времени; превышение должно вызывать отказ или постановку в очередь.  

Квота (quota) — ограничение количества ресурсов (например, запросов или времени) для обработки части задачи; превышение приводит к отказу и возвращается одинаковый код отказа.  

Тестовый набор — набор входных данных (пустой, один элемент, полный набор), используемый для проверки поведения функции в различных сценариях.  

Очередь — структура, хранящая задания в порядке их поступления.  

Исполнитель — процесс, берущий следующее задание из очереди после завершения предыдущего.  

Состояние — метка задания (в очереди, выполняется, готово, ошибка), определяющая его текущий статус.  

Прогресс — показатель количества завершённых частей задания, а не оценка оставшегося времени.  

Лимит — предельное число запросов или ресурсов; превышение должно возвращать одинаковый код отказа.  

HTTP — протокол передачи гипертекстовых данных между клиентом и сервером.  

GET — метод, используемый для чтения текущего состояния ресурса без изменения его.  

POST — метод, создающий новый ресурс или инициирующий действие на сервере.  

202 Accepted — статус‑ответ, означающий, что запрос принят, но результат ещё не готов; клиент должен опрашивать указанный в заголовке Location адрес.  

400 Bad Request — ошибка, указывающая на некорректность сформулированного клиентом запроса.  

404 Not Found — ошибка, означающая отсутствие запрашиваемого ресурса на сервере.  

Очередь ограничений — механизм, позволяющий серверу откладывать превышающие лимит запросы вместо их тихого игнорирования.
