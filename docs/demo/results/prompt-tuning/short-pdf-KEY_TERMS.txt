Алгоритм — конечная последовательность понятных исполнителю шагов для решения задачи.

Линейный поиск — алгоритм, просматривающий элементы массива последовательно и работающий даже в неотсортированном массиве; в худшем случае проверяет все n элементов.

Бинарный поиск — алгоритм, требующий отсортированного массива; после каждого сравнения отбрасывает половину оставшегося диапазона, а число шагов растёт пропорционально логарифму n.

Модульный тест — проверка небольшой части программы отдельно от внешних систем.

Заглушка — заменяющий зависимость предсказуемый объект, который возвращает заранее заданный ответ вместо реального вызова.

Интеграционный тест — проверка совместной работы нескольких компонентов системы.

HTTP‑тест — отправка настоящего запроса к локальному серверу с проверкой кода ответа, заголовков и тела.

Положительный сценарий — тест, демонстрирующий корректную работу запроса при правильных данных.

Отрицательный сценарий — тест, проверяющий корректную обработку ошибки при неверных данных.

Воспроизводимость тестов — свойство, при котором обычный запуск тестов не зависит от доступности внешних API или секретных ключей.
