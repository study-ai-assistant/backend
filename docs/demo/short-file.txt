Модульный тест проверяет небольшую часть программы отдельно от внешних систем. Заглушка заменяет зависимость предсказуемым поведением: например, вместо вызова языковой модели возвращает заранее заданный ответ. Интеграционный тест проверяет совместную работу нескольких компонентов. HTTP-тест отправляет настоящий запрос локальному серверу и проверяет код ответа, заголовки и тело. Положительный сценарий показывает, что корректный запрос работает. Отрицательный сценарий проверяет понятную ошибку при неверных данных. Тесты должны быть воспроизводимыми: обычный запуск не должен зависеть от доступности внешнего API или секретного ключа. Проверка через curl дополняет автоматические тесты, но не заменяет их.
