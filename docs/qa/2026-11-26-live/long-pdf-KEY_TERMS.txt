Инвариант — условие, которое программа сохраняет до и после операции; его нарушение приводит к отмене операции без частичного изменения состояния

Пустая коллекция — допустимый вход, если контракт явно не запрещает отсутствие элементов

Ограничение (входа) — предел размера или частоты запросов; при превышении сервер сообщает об отказе или ставит запросы в очередь

Контракт — формальное описание требований к входным данным и ожидаемому результату, которое должно совпадать в запросе и ответе

Граничное значение (граничные значения) — набор тестовых данных, находящихся на пределе допустимого диапазона (допустимый максимум, значение на единицу меньше и значение на единицу больше)

Линейный поиск — последовательное сравнение каждого элемента с образцом; в худшем случае требуется n сравнений для n элементов

Бинарный поиск — поиск в отсортированном диапазоне с делением пополам; корректность требует предварительной сортировки

Оценка O(n) — асимптотическая сложность алгоритма, показывающая линейный рост количества операций от числа элементов

Асимптотический анализ — оценка роста затрат при увеличении входных данных без указания точного времени исполнения

Очередь — структура, хранящая задания в порядке их поступления и передающая их исполнителю последовательно

Фоновые задания — задачи, выполняющиеся асинхронно после получения клиентом идентификатора; их статус проверяется отдельно

Статус задания — текущее состояние задания (в очереди, выполняется, готово, ошибка), отражающее прогресс выполнения

Прогресс — количество завершённых частей задания, а не приблизительная оценка оставшегося времени

Временное хранение — механизм сохранения данных на ограниченный срок с последующим удалением; очищается после перезапуска или завершения сеанса

Освобождение ресурсов — процесс очистки памяти и других ограниченных средств после завершения работы функции, не гарантирующий корректность данных

Квота — лимит времени или количества операций, ожидаемый между обработкой частей, либо ограничение количества запросов/заданий за фиксированный период; превышение приводит к отказу или постановке в очередь

Режим — именованная конфигурация запроса, название которой должно совпадать в запросе и ответе сервера

HTTP‑метод GET — запрос, предназначенный только для чтения состояния ресурса

HTTP‑метод POST — запрос, создающий ресурс или инициирующий действие; при повторной отправке может приводить к повторному созданию задания

Код ответа 202 — подтверждение принятия задания сервером без готового результата; требует последующего опроса по адресу из заголовка Location

Условие проверки — требуемый предварительный тест, выполняемый до начала работы для подтверждения корректности исходных данных и настроек

Успешный исход — результат выполнения запроса, подтверждающий завершение конкретного действия и наличие итогового результата

Отказ — ответ сервера, указывающий на невозможность выполнить запрос (например, превышение лимита или ошибка ограничения)

Повторная попытка — повторный запрос клиента, требующий предоставления сведений о причине отказа, но без включения содержимого документа или секретных настроек

Согласованные поля — взаимосвязанные параметры, которые одновременно читают несколько клиентов и должны показывать одинаковую информацию (например, число завершённых частей не превышает общее число частей)

Перезапуск — действие, после которого память очищается, и клиент может потребоваться заново отправить данные; свойство временного хранения следует объяснить заранее

Тест — проверка с известными входными данными и ожидаемым результатом, часто использующая заглушку внешнего сервиса для имитации успеха, отказа и задержки

Пиковая память — максимальное количество памяти, использованное при обработке материала; измеряется отдельно и не заменяет оценку качества ответа

Число вызовов — количество обращений к функции или сервису во время выполнения; фиксируется отдельно и не является единственным индикатором корректности

Длительность — суммарное время выполнения обработки; измеряется независимо от памяти и числа вызовов

Таймаут — ограничение максимальной длительности разбора запроса; при превышении запрос прерывается

Успешное задание — запрос, в котором присутствует итог, подтверждающий завершение

Успешный ответ сервера — сообщение, подтверждающее выполнение конкретного запроса, но не гарантирующее отсутствие ошибок в других документах

Проверка — процесс сверки определений и вычислений с исходным материалом для выявления несоответствий

Ограничения — найденные пределы или условия, которые необходимо зафиксировать и воспроизвести при тестировании

Синтетические данные — искусственно сформированные наборы информации, используемые в учебных примерах проекта
