Инвариант — условие, которое программа обязана сохранять как до, так и после выполнения операции.  

Граница изменения данных — момент, в котором проверяется соблюдение инварианта; при нарушении операция завершается ошибкой без частичного изменения состояния.  

Пустая коллекция — допустимый вход, если контракт не запрещает её; считается нормальным случаем.  

Ограничение входа — предельный размер или количество запросов, при превышении которого сервер должен отказать или поставить запросы в очередь, а не терять их незаметно.  

Квота (quota) — ограничение, учитывающее как время ожидания, отдельное от чистого времени выполнения частей, так и количество запросов за единицу времени (например, 30 запросов/минуту).  

Контракт — формальное описание входных параметров, допустимых значений и ожидаемого результата, которое должно совпадать в запросе и ответе.  

Граничные значения — набор тестовых входов, включающий максимум допустимого значения, значение на единицу меньше и значение на единицу больше (для проверки краевых случаев).  

Согласованные поля — данные, которые несколько клиентов должны видеть одинаковыми (например, число завершённых частей не превышает общее число частей).  

Линейный поиск — последовательное сравнение элементов с образцом; в худшем случае для n элементов требуется n сравнений.  

Бинарный поиск — поиск в отсортированном диапазоне, который делится пополам; без сортировки корректность результата не гарантируется.  

O(n) — асимптотическая оценка, описывающая рост затрат при увеличении входных данных, а не конкретное время выполнения.  

Ограничение запросов (rate limit) — предельное число запросов, которое сервер может обработать (например, 20 – 40 запросов за фиксированный интервал); превышение должно приводить к отказу или постановке в очередь.  

Код отказа — одинаковый идентификатор ошибки, возвращаемый при повторных превышениях лимита.  

Память после перезапуска — состояние, при котором вся временная память очищается, и клиент может потребовать повторную отправку данных.  

Очередь — структура, хранящая задания в порядке их поступления.  

Задание — единица работы, получающая клиентом идентификатор и статус.  

Состояние — один из фиксированных статусов задания: в очереди, выполняется, готово, ошибка.  

Прогресс — показатель завершённых частей задания, а не оценка времени.  

Ошибка — ситуация, при которой часть задания не может быть возвращена как итоговый ответ; требуется отказ или повтор.  

Временное хранение — хранение данных с ограниченным сроком, после которого они удаляются.  

GET — метод HTTP, который читает текущее состояние ресурса.  

POST — метод HTTP, который создаёт новый ресурс или инициирует действие.  

202 Accepted — ответ сервера, означающий, что запрос принят, но результат ещё не готов; клиент должен опрашивать адрес из заголовка Location.  

400 Bad Request — ошибка, указывающая на неверно сформированный запрос.  

413 Payload Too Large — ошибка, указывающая, что размер передаваемых данных превышает допустимый предел.  

404 Not Found — ошибка, указывающая, что запрашиваемый ресурс отсутствует.
