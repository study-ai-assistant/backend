# Проверка PDF на учебных материалах

Дата: 10.11.2026. PDFBox 3.0.8, Java 21, Linux. LLM не вызывался.
Проверены пять настоящих документов: два конспекта MIT разного оформления,
русские лекции по алгебре, учебные заметки Stanford и научная статья.
Скачанные PDF и извлечённые тексты не добавлены в репозиторий. В нём сохранены
только ссылки, SHA-256, размеры и результаты измерений.

## Методика

Для каждого документа выполнено по три запуска в двух режимах:

1. **Обычные ограничения:** 50 страниц и 10000 символов. Это проверка поведения,
   которое получит клиент. Текст не обрезается; превышение даёт 413 до вызова LLM.
2. **Оценка качества:** тот же PDFBox и worker, но с лимитом 1000000 символов
   только в исследовательском запуске. Это позволяет проверить весь текст документа.
   Ограничение HTTP API при этом не менялось.

Worker запускается из собранного Spring Boot JAR.
Каждый запуск использует новый Java-процесс с `-Xmx128m` и metaspace до 96 МиБ.
Время разбора измеряется внутри worker (включая формирование его ответа),
время процесса — снаружи, со стартом JVM. Память — Linux `wait4().ru_maxrss`,
то есть максимальный RSS **всего дочернего процесса**, а не размер PDF и не только Java heap.
RSS не является потреблением памяти основного сервера. Замеры локальные,
без нагрузки другими HTTP-запросами, это не нагрузочный тест.

## Качество и проблемные случаи

Проверены извлечённые тексты и визуальные страницы источников; это ручная оценка,
а не сравнение с полным размеченным эталоном.

| Материал | Наблюдение | Что делаем |
|---|---|---|
| MIT 2011 | Основной текст и заголовки читаются; рисунки не превращаются в описание, часть подписей оказывается отдельно | Не обещаем понимание диаграмм; OCR и анализ изображений — отдельная работа |
| Русская алгебра | Кириллица читается, порядок страниц сохранён; остаются переносы слов. В формулах отдельные знаки и индексы искажаются, например знак неравенства может стать двумя символами | Не подменяем символы догадками; предупреждаем об ограничениях формул. Очистка переносов относится к подготовке текста |
| Stanford CS229 | Текст и числа таблицы доступны, но сетка таблицы теряется; подписи графика и части формул попадают в общий текст | Не выдаём результат за структурированную таблицу или точную математическую запись |
| Attention | Основной текст извлечён, но таблицы, рисунки и сложное расположение подписей требуют ручной проверки | Не гарантируем сохранение структуры научной статьи; длинный документ получает 413 |
| MIT 2020 | Списки и абзацы читаются; геометрия страницы, разрывы строк и заголовки сохраняются только как обычный текст | Подходит для короткого текстового материала, формат документа не восстанавливаем |

Символ замены U+FFFD в результатах не встретился. Это не доказывает точность формул:
ошибка может выглядеть как другой корректный символ. В двух документах обнаружены
единичные служебные символы. Их автоматическая нормализация не добавлена в разбор;
это отдельная задача подготовки текста. Полные тексты не включены в отчёт.

## Выбор ограничений

Оставлены **50 страниц** и **10 секунд**. В выборке 5–39 страниц, максимальное
время полного процесса — около 2.7 секунды. Такой запас покрывает холодный старт
и более медленные машины; тестовая PDF из 50 страниц также принимается.
Документ с 51 страницей отклоняется до извлечения текста. Повышать лимит только
ради одного длинного конспекта не стоит: 10000 символов всё равно ограничивают запрос.

Для worker выбран heap **128 МиБ**, максимум **два параллельных разбора**.
В этой выборке полный RSS достигал примерно 207 МиБ на процесс. Heap не ограничивает
весь RSS JVM; два процесса могут использовать порядка 414 МиБ вместе, плюс основной
сервер. При меньшем доступном объёме памяти следует выставить PDF_MAX_CONCURRENT=1.
Если worker исчерпал память или не смог разобрать файл, текст не отправляется в LLM.

По истечении таймаута сервер принудительно завершает дочерний процесс, дожидается
его остановки, удаляет временную папку и освобождает слот. Зависший PDFBox не остаётся
в потоке основного сервера. При занятых слотах возвращается 503 без очереди.

## Как повторить

Нужны Java 21, Maven Wrapper, Python 3 и Poppler (`pdfinfo`) на Linux.
Скачайте файлы по ссылкам **в папку вне репозитория**. Положите туда sources.json:
массив объектов name/url/bytes/sha256 из JSON-отчёта. Имена PDF: `<name>.pdf`.

```bash
./mvnw -DskipTests package
python3 tools/pdf/benchmark.py /путь/к/материалам --jar target/backend-0.0.1-SNAPSHOT.jar
```

Скрипт не скачивает файлы и не вызывает LLM. Он сверяет SHA-256, выполняет замеры,
сохраняет measurements.json и полные тексты только в указанной внешней папке.
Это диагностический запуск; лимит 1000000 в нём не доступен через HTTP.
