# API

Основной контракт: `docs/api/openapi.yaml` в репозитории backend.
Статус обработки текста — **черновик**, требуется review mobile (#4).

| Метод | Путь | Назначение | Статус |
|---|---|---|---|
| GET | /health | 200, JSON {"status":"ok"} | Работает |
| GET | /api/v1/modes | Массив пяти режимов | Работает |
| POST | /api/v1/text/process | JSON text + mode → mode + result | Контракт; реализация #8, сейчас 404 |
| GET | /actuator/health | Техническая проверка Spring | Работает |
| POST | /api/v1/materials/process | Старая multipart-заглушка | 501; вне контракта спринта 1 |

Протокол HTTP для локальной разработки, JSON UTF-8. Внешнее развёртывание
требует HTTPS. Адрес Android-эмулятора: http://10.0.2.2:8080;
телефон в той же сети использует локальный IP компьютера.

## Рабочая проверка

```bash
curl -i http://localhost:8080/health
curl http://localhost:8080/api/v1/modes
```

## Планируемая обработка текста

```json
{"text":"Митохондрии обеспечивают клетку энергией.","mode":"SHORT_SUMMARY"}
```

Будущий успешный ответ HTTP 200:

```json
{"mode":"SHORT_SUMMARY","result":"Митохондрии снабжают клетку энергией."}
```

Предложение: до 10000 Unicode-символов; text не пустой и не только пробелы.
400 — неверные поля, JSON, пустой текст или неподдерживаемый режим;
413 — превышен лимит; 502 — ошибка, квота или таймаут LLM.
Ошибки в application/problem+json. Пример:

```json
{"type":"about:blank","title":"Bad Gateway","status":502,"detail":"Сервис обработки текста временно недоступен. Повторите запрос позже.","instance":"/api/v1/text/process"}
```

Серверный таймаут LLM предлагается 60 секунд, клиентский — 90 секунд.
В первом шаге #8 достаточно SHORT_SUMMARY; остальные режимы возвращают 400
до реализации. Повтор POST может повторить обработку; не повторять автоматически.
Полные примеры и схема — в OpenAPI. Эти ответы пока не реализованы и не проверены
реальным запросом к LLM. Ключ никогда не передаётся мобильному клиенту.
