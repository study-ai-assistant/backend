## Настройки сервера

Файл .env.example содержит пустые значения и комментарии; скопируйте его
в .env и заполните свой файл. Для Groq локальные значения:

```properties
LLM_PROVIDER=groq
LLM_MODEL=openai/gpt-oss-120b
LLM_BASE_URL=https://api.groq.com/openai/v1
```

LLM_API_KEY заполните самостоятельно своим новым ключом. В документации
и сообщениях ключ не показывать. Сервер привязывает параметры к LlmProperties;
GroqLlmClient уже вызывает API для SHORT_SUMMARY (реализация №8 включена в ветку).
Для альтернативного провайдера понадобится соответствующий адаптер.

Groq Console: https://console.groq.com/ → API Keys → Create API Key.
Ключ хранится только в локальном .env либо окружении процесса; .env исключён
из Git и Docker-контекста.

## Лимиты Groq

Базовые ограничения Free Plan для
openai/gpt-oss-120b: 30 запросов/мин, 1000 запросов/день, 8000 токенов/мин,
200000 токенов/день. Лимиты действуют на организацию, не на каждый ключ.

## Режимы

| Идентификатор | Результат |
|---|---|
| SHORT_SUMMARY | Краткий конспект |
| DETAILED_SUMMARY | Подробный конспект |
| SIMPLE_EXPLANATION | Объяснение простыми словами |
| SELF_CHECK_QUESTIONS | Вопросы для самопроверки |
| KEY_TERMS | Ключевые термины |

Идентификаторы соответствуют ProcessingMode и OpenAPI. Сейчас генерация
работает только для SHORT_SUMMARY; остальные режимы возвращают 400.
Примеры учебных текстов для ручной проверки не должны содержать персональные данные.

## Реальный вызов и диагностика

Нужны все параметры LLM_PROVIDER=groq, LLM_MODEL, LLM_BASE_URL и LLM_API_KEY.
URL вызова: базовый URL без завершающего слеша + /chat/completions.
Ключ передаётся как Authorization: Bearer только между сервером и Groq.
Отсутствие настроек даёт 502 при обработке, но не мешает запуску /health.

Подключение ограничено 5 секундами; read timeout и общее ожидание — 60 секунд.
Некорректный/пустой ответ, HTTP-ошибка, квота или сеть дают общий 502 без ответа провайдера.
LLM может сформулировать конспект по-разному. Система просит русский обычный текст
без добавления фактов, но качество нужно проверять на реальных учебных примерах.
Инструкция не является гарантией защиты от всех инструкций внутри материала.

Тесты GroqLlmClient используют локальный имитатор HTTP API и не расходуют реальную квоту.
Для ручной проверки: заполнить свой .env, перезапустить сервер и отправить пример
из docs/api/examples/short-summary-request.json по инструкции docs/api/README.md.
